# Customer assets

Ảnh và SVG được tải từ Figma `JImBbTpHu4JczBDfKVlVzu`, các frame Customer/Auth, bằng asset URLs do MCP trả về. `figma/sources.json` ghi frame, constant, file và kích thước file. Các URL tạm thời không được dùng lúc chạy.

Icons trong Figma là Tabler Icons (MIT), giữ nguyên SVG xuất từ thiết kế. Ảnh sự kiện, đơn và vé chỉ dùng URL do API trả về. Ảnh Figma tĩnh dùng cho Auth và minh họa địa điểm có chú thích; không dùng để tạo nội dung sự kiện giả. Không còn đường chạy mock/preview trong Customer.

Fonts: Be Vietnam Pro Regular/Medium/SemiBold/Bold, Outfit Bold, Lora Bold, tải từ [Google Fonts](https://github.com/google/fonts). Outfit/Lora Bold được tạo instance wght=700 từ font variable chính thức. Giữ OFL licenses bên cạnh fonts.
