# Customer/Auth — bảng đối chiếu từng frame

Nguồn: Figma section **9:878 (73 frame Customer)** và **9:877 (6 frame Auth)**. Tên/ID giữ nguyên từ [inventory](customer-frame-inventory.json). Đã đọc design context và screenshot của cả 79 frame, kiểm tra controls/prototype destinations; không sửa Figma.

“Đã dựng” nghĩa là route/component và cấu trúc tương ứng đã có trong code. Không có nghĩa màn đã qua kiểm tra runtime hoặc pixel matching trên native. Các nhánh kết quả chưa được server cung cấp dùng khung thông tin chưa xác định, không phát sinh trạng thái thành công giả. Mọi hàng dưới đây **đã dựng nhưng chưa kiểm tra runtime bằng dữ liệu thật**. Chỉ màn lỗi thiếu cấu hình ở root đã chạy trên web hiện tại; chưa chạy Android/iOS native. Chưa kết luận UI/UX hoàn thành kiểm chứng toàn bộ.

Ký hiệu API trong bảng là contract trong checkout đã nối wrapper; **không phải xác nhận dịch vụ live đã chạy**. Các ID trong URL route phải đến từ record thật. Không có menu preview, mock fallback hoặc link đến mã đơn/vé mẫu. Tình trạng runtime được ghi trực tiếp trong bảng; không giữ bản JSON trùng nội dung.
